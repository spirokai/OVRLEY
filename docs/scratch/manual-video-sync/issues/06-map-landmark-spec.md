# What is the spec for map-landmark sync mode?

Status: ready-for-agent
Labels: wayfinder:grilling

## Question

Once OVRLEY has real map tiles, what should the map-landmark fallback sync mode look like? Define the interaction flow, the data requirements, how a single map landmark disambiguates the offset, and how the mode relates to the 2–3 turn/stop landmark mode. The output should be a spec document that can be handed off when map tiles are added.

## Blocking

None in this map. This ticket is blocked externally on OVRLEY adding real map tiles and a map-tile rendering package.
