# Domain Docs

How the engineering skills should consume this repo's domain documentation when exploring the codebase.

## Before exploring, read these

- **`AGENTS.md`** (`agents.md` at the root): the project, its crates, code rules, commands.
- **`docs/ARCHITECTURE.md`**: the crates, the update loop, MCP, export and packaging.
- **`docs/MCP.md`**: what agents can do in the app.

There is no glossary and there are no ADRs. Use the names the code uses (crates, features, catalog types) in issue titles, plans and test names.
